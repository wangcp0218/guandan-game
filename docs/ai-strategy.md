# AI 决策与公开信息分析

默认后端为 DeepSeek 官方接口的 `deepseek-v4-flash`，使用服务端
`DEEPSEEK_API_KEY`；`DEEPSEEK_BASE_URL` 和 `DEEPSEEK_MODEL` 可覆盖默认配置。
Qwen 节点高负载期间默认使用 DeepSeek，Fueternal `Qwen3.8-27` 仍可手动选择。
Qwen 的内部 provider 保留为 `local`，大厅显示为 Qwen（Fueternal）。

服务端需要 `LOCAL_LLM_API_KEY`（也可使用 `FUETERNAL_API_KEY`）；
`LOCAL_LLM_BASE_URL` 可覆盖默认接口根地址。密钥仅放在服务端环境变量或未提交的
`.env` 中。启动时读取工作目录的 `.env`，已有进程环境变量优先。
本机仓库根目录和 `server/` 已配置忽略提交的 `.env`，支持从根目录直接启动或
`npm run dev -w server`。部署时需另行在目标服务器配置环境变量，源码包不包含密钥。

Qwen 请求输出额度为 4096 tokens，为推理和最终动作 JSON 留出空间；
模型请求仍保留 20 秒超时，失败时继续使用本地策略兜底。
Qwen 请求显式发送 `enable_thinking=false` 和
`chat_template_kwargs.enable_thinking=false`；节点是否实际关闭思考需以响应验证。

## 本机部署

- 本机服务：`guandan-game.service`，工作目录 `/root/guandan-game`，端口 `3000`。
- 公网入口：`https://182222.xyz/guandan/`，由 VPS Nginx 经 FRP `33340` 转发到本机。
- Nginx 模板：`deploy/nginx/guandan-location.conf`。
- `.env` 保存模型凭据、`JWT_SECRET` 和 `PUBLIC_BASE_PATH=/guandan`，不提交。
- 更新：`npm run build -w server` → `VITE_BASE_PATH=/guandan/ npm run build -w client`
  → `systemctl restart guandan-game`。

当前流程：生成合法动作 → Base7 风格评分、PASS 评分与策略护栏 →
模型调用门控 → 手牌拆分分析 → 残局隐藏手牌加权抽样续打 →
将分层候选和分析结果交给房间选择的大模型。
模型不可用或输出无效时使用本地分析结果兜底。没有接入训练模型或在线训练。

每回合用已有合法动作和公开状态选择一个轻量团队目标：直接走完优先，
对手报单/报双时防守，对家报单/报双时尝试送牌，其次利用两手走完的结构争先，
其余情况整理手牌。两张余牌不被当作确定的对子。
接管对手牌权时，只有仍留有合适的小单/小对才增加送牌收益；
已知贡牌帮助判断对家能否接住，未见牌池帮助保留对应控制张。
原有完整公开记牌、过牌软证据和残局抽样继续使用，不读取其他人的实际手牌。
团队目标同时影响本地排序并进入现有模型请求，无额外模型调用或新搜索框架。

自己剩 2–8 张时，复用合法动作检查“小牌试探→同型控制张回手→尾牌”路线，
若对手可能用试探牌型直接走完则放弃该路线；试探回手没有公开牌力证明时只给较低奖励。
若公开记牌证明控制张无法被压，且打出后余牌可一手走完，则允许先控后走。
路线影响领出评分，也随原有候选分析发送给模型，不额外调用模型或展开完整博弈树。
平静领出时取消“已知最大单/对”的额外奖励，保留同类牌先小后大的倾向。

跟牌时，本地动作排序与 PASS 比较共用完整评分（结构变化、回手与资源成本）。
结构损伤相对于原手牌计算，避免只向出牌动作收取本来就存在的弱牌成本。
真正的自然散单只有软评分奖励；属于顺子、同花顺、连对或钢板的独特点数不算散单。
模型的 PASS 保持不出，除非能直接整手走完；报单/报双时已选择跟单/跟对的动作，
在最终返回前保证使用最大合法单/对，后续小牌优先逻辑不能再降级。

## 信息边界

- `GameRoom.publicActionHistory` 保存本局全部公开出牌和过牌，在下一局清空。
- 各家余牌数由起始 27 张减去公开出牌数推算，不读取其他人的实际手牌。
- `buildPublicKnowledge` 从两副牌减去自己的当前手牌和全部已出实体牌，生成未见牌池。
  逢人配按原始实体牌扣除，不按其声明的替代牌扣除。
- 公开进贡、还贡形成已知牌的归属约束；已经打出的贡牌不再锁定。
- 不使用复盘中的四家起始手牌。“不出”只作为软证据：能接牌越多的隐藏分配权重越低，
  但不会因一次过牌被硬排除。队友领牌时的过牌不作负面推断。
- 公开牌力证明将三家未见牌合并为最强可能对手；只有该合并牌池仍无法压制时，
  才把单张/对子标记为可证明的控制牌。炸弹和同花顺可能性包含逢人配。
- 同一对手连续通过后续玩家的 PASS 拿回牌权时，累计公开控牌压力，逐轮降低 PASS 价值。
  该压力不用于压队友，队友让牌护栏保持不变。
- 完整公开历史、未见牌汇总、贡牌转移以及本地分析结果一起进入大模型输入。

## 手牌最少出几手

对合法动作对应的实体牌子集进行不重叠拆分。最多分析前 40 个候选的剩余手牌，
共享记忆化搜索；默认约 80ms 和 20,000 个搜索节点预算。

`exact=true` 表示已证明最少手数；`exact=false` 表示限时返回的一种可行拆分上界。
该手数假设可以连续自由出牌，不包含对手拦截、队友让牌或实际可获得的牌权。
剩余手数影响候选排序，但不单独决定动作。

## 残局抽样

触发条件：四人合计剩余不超过 24 张，自己不超过 10 张，并且完整公开信息可用。
从未见牌池按余牌数和公开贡牌归属产生合法分配，再用历史过牌一致性软加权，
比较最多 6 种候选及合法的“不出”。
默认最多 256 组样本，总分析预算约 800ms（在计算步骤间检查，并在样本间让出事件循环）。
若公开约束下全部实体牌分配不超过256种，完整枚举分配并用规则AI续打，
汇总时同样使用历史行动权重。
这不是minimax，也不是不完全信息最优解；枚举超时会舍弃所有前缀统计，避免有偏估计。

每组样本对所有候选使用同一份抽样手牌，后续由规则 AI 续打，处理接风、双方名次、
双上提前结束和第三名出完后结算。各模拟选手决策只获得自己的抽样手牌及公开局面。
未完成整组比较的样本全部舍弃；至少 8 组配对样本且平均收益差超过随样本数收缩的保守门槛，
才允许模拟推翻本地基线选择。

评分目标为带正负号的升级收益：本方赢为正，对方赢为负，按升 1/2/3 级归一化。
同时报告样本胜率与双上率。它们是少量样本在规则 AI 续打下的统计值，不是经过校准的真实胜率。
当前没有对未知手牌使用学习过的概率分布，也没有全树博弈求解；提示词要求谨慎使用这些估计。

## 候选覆盖与策略边界

实体牌等价选择先压缩为同一战略声明，再按牌型分层轮询保留最多 96 个候选；
每种已出现的牌型都至少保留一个高分代表，同时保留全局排名第一的候选。
回手评分区分低张与A以上同型控制，不能据此声称必然封死对手。
残局降低使用王和逢人配的成本，模型temperature为0；不承诺调用完全确定。
提示词区分领出/跟牌、暂时拦截/持续控权、整手清空/留下弱尾牌以及接风条件。

尚未实现：完整不完全信息minimax、独立策略规划调用、三次模型投票、
学习式推断、自动调权和ELO评测。当前回归测试不等同于牌力提升证明。

## 评估与观测

- `npm run benchmark:ai -w server -- 100` 使用固定种子发牌，让候选策略和基线策略在同一份牌上交换队伍，
  输出平均升级收益、胜率和双上率。默认 runner 使用相同策略做对称性自检；
  对比新旧策略时调用 `evaluateStrategies(candidate, baseline)`。
- `node scripts/compare-ai-revisions.cjs 1000 reports/ai-self-play-2026-09-18 280ee3a 8ad13ea`
  从两个提交建立临时源码快照并编译，使用各自的 `findBestPlay` 对战。
  每级牌（2–A）生成 1,000 组固定种子牌，交换队伍共 26,000 局；输出逐局 JSONL、
  分级牌汇总及以配对发牌为统计单位的近似 95% 置信区间。最多使用 4 个计算线程。
  此评估不调用大模型，采用无进贡的独立单局，不等同于完整升级比赛或智能 AI 实战。
- 生产进程只累计脱敏指标：决策数、智能决策数、异常数、决策/模型耗时、prompt 字符数和模型结果分类。
  不记录手牌、prompt、玩家或房间标识；每 100 次 AI 决策输出一次汇总。

## 统一裁决与团队模拟

模型回复与模型不可用时的本地兜底共用最终裁决：出牌和 PASS 使用相同的配对模拟升级收益比较。
至少 8 份完整配对样本、收益差超过保守阈值时，允许推翻原选择；未模拟的动作不凭空赋予胜率。
“通常不压队友”和“同结构先小后大”保留为偏好，但充分的团队收益证据可以推翻；
接管队友牌不再额外要求对手已剩 5 张以内。直接走完和报牌拦截仍保留既有保护。

残局模拟最多比较 8 个出牌候选及 PASS，优先覆盖试探路线、单/对控制、送牌与剩余结构。
沿用 800ms 总分析预算和小残局启动条件，不增加模型调用。
模拟中的每名玩家保留原公开历史、公开进还贡，并看到模拟中新增的出牌与过牌；
只读取自己的抽样手牌，不读取其他玩家的底牌。模拟缓存包含公开历史，避免不同牌局证据混用。
这是现有规则续打模拟的改进，尚非完整博弈树求解，也未通过对战评测证明牌力提升。

统一裁决补充：报单/报双使用最大牌也作为强偏好，完整配对模拟显示明显团队收益时允许例外。最终比较修正后的动作，并固定原基线，避免候选顺序或连续小差异改变结论。

小残局应对分支：全场余牌不超过 12 张时，对每份抽样、每个候选分别续打常规、首个对手主动控权、首个对手让牌三种应对。主动控权优先直接走完，其次强普通牌或最小炸弹。三种情景等权汇总，但样本数仍按隐藏牌分配计数，不将三个分支冒充三个独立样本。任何分支超时则整组不计入，保持候选可比；继续受 800ms 总预算限制。这是有限应对分支，不是完整博弈树求解。

团队路线比较：每轮分析生成可执行的“自己走、送队友、接管后换牌型、让牌保控制”备选。送牌检查接管牌与续牌不重叠，标出队友之前可能直接走完的对手座位；两张余牌同时考虑单和对，完整公开贡牌可排除接不上的牌型。路线对应具体候选/PASS，优先进入有限模拟，并把相同口径的升级收益和后续牌型传给模型。没有可行接管或送牌时不会虚构路线；无模拟时仍明确保留不确定性。

行为推断：以公开历史回放每份可能的手牌分配。有便宜散单/完整对子却过敌方牌会轻微降低该分配权重；保对子、炸弹、王或逢人配以及让队友牌不作同等惩罚。可用低散单却主动拆组作为额外软证据，历史累计权重设下限，任何一种持牌仍有可能。回放按实际剩余人数重置牌轮。
每轮在现有时间预算内最多生成 16 份加权样本，向模型提供各家高牌存在可能性、两张余牌为对子的可能性及样本数。队友两张且样本更支持散单时，初始送牌倾向改为单张，但保留多路线比较。概率未经校准，不作为底牌事实；未新增模型调用。

调用精简：同一轮智能决策复用合法组合，不重复生成供规则兜底和手牌结构排序使用的组合；候选描述复用手牌计数。模型只返回动作编号和简短理由，移除程序不使用的意图、置信度和风险输出。团队路线通过动作编号引用候选模拟结果，避免重复发送同一统计。保持候选覆盖、公开信息、模型思考配置和超时设置不变。

让牌应对修正：残局的保控制分支也优先合法直接走完，避免把对手主动放弃获胜机会计入试探收益。

PASS 评分按实际未完成玩家、连续过牌次数判断本次让牌是否结束牌轮，区分后面仍有队友能应对、最后拦截机会以及接风后的领牌者。对手余牌少改为有限的压力分，不再直接把 PASS 设为 -10000；保留结构和控制牌的价值仍可参与比较。

队友牌改用有限让牌偏好，仍保护临近走完或已获本轮牌权的队友。中盘新增具体接管例外：队友余牌至少 6 张、领出的普通牌较小、对手未报单/双，且自己能用完整散控制单/对接管、不拆组或逢人配，并保留至少 3 张的整手出口时，允许接管推进团队。对敌方接管后保留整手出口也加分。此路线只代表有价值的续牌，不保证对手不会再压；其他接管仍需公开拦截依据或充分模拟证据。

三带二附带牌保护：同一三张点数下，允许最终策略比较牌力相同但对子不同的候选，优先保留不影响余牌结构的王对、级牌对等控制资源。附带对子单独计算控制成本；直接走完仍优先，唯一合法三带二不被禁用，充分配对模拟收益仍可支持使用控制对。

## 完整复盘保存

每轮结算时自动写入 `data/replays/<房间ID>-round-<局数>.json`，包含时间、该局实际级牌、玩家座位、完整结构化出牌/过牌，以及含进还贡后初始手牌的页面复盘与最终名次。每局独立保存，下一局和进程重启不清除文件；先写临时文件再重命名，保存失败不阻止结算。复盘目录已由 `/data/` 的忽略规则排除出 Git。该功能需要服务加载新版本后生效，不能补回此前仅存在浏览器中的记录。

三局复盘改进一：低A23/234连对单独计入级牌与A的控制成本，避免只按一次出六张奖励；直接走完仍优先。

三局复盘改进二：候选附带本手加余牌相对原拆分新增的手数、精确性及最大保留牌组。精确拆分证实平静局面炸牌多出至少两手时，最终裁决允许让牌；报单/双、连续控权、已经产生名次或明确模拟收益时保留防守例外，不机械禁止第二局的高代价拦截。

三局复盘改进三：队友头游后优先争二游，二游已定后争三游。大手牌未启动残局模拟时，若对手连续领牌或剩5张以内、且本地已有合法接管方案，模型无模拟依据的PASS可由该方案纠正；本地也让牌、已有配对模拟、对手已经走完时不强行抢权。模型候选保留本地接管方案，避免压缩时丢失。

第四局复盘改进：无配对模拟时，对手连续领牌会触发具体接管比较，优先使用完整普通牌（含散王）并保留真实的成组续牌；临近走完仍保留本地防守，报单且本次PASS将结束牌轮时检查最后合法拦截。队友领牌与已走完对手不适用此压力规则。模型新增从完整公开历史汇总的连续领牌次数、自己期间过牌次数；阶段以全桌余牌、已完成名次及出牌进程判断，避免自己牌多就永远视为开局。不增加模型调用，不共享私有手牌，也未把臆测的上一轮计划当作事实。
