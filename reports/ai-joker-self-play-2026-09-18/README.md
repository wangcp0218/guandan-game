# 用王压级牌 self-play 评估（2026-09-18）

结论：新版更愿意用王接管对手单张级牌，但本次样本未显示整体实力显著提升，也未显示显著退步。不据此调整参数或宣称胜率改善。

## 方法

- 候选：评估时工作区源码快照；旧版：`5ad284af9a53ae23056765cbbc8e0af6d99332e7`，即本次改动前 HEAD。差异见 candidate.patch。
- 2–A 共 13 个级牌，每级 100 组独立发牌，每组交换两队策略，共 1,300 组、2,600 局。
- 固定发牌种子：20260918 + (level - 2) * 100000 + index，index=0..99；每局座位 0 先出。
- 双方运行各自的 findBestPlay，只读取自己手牌及公开信息。没有调用大模型，因此没有评价新增提示词或恢复模型调用门控的实战效果。
- 每局独立，无进贡、无连续升级比赛；双方级数相同。
- 胜率指获得头游，双上率以全部对局为分母；净升级收益按本方胜负记 ±1/2/3 级。
- 95% 置信区间按同一发牌换队两局的平均值计算，采用正态近似。
- 四个工作线程，耗时 234.9 秒。种子唯一性、每级数量、总局数和胜局汇总均核验通过。同版本单组重复运行检查通过。
- 手数搜索使用 4ms 时间预算，机器负载可能改变搜索深度；固定种子不保证逐局结果完全复现。

## 是否改变用王行为

统计条件：跟对手单张级牌，且自己持有至少一张王（包括王对、四王炸中的王）。

| 实际对战轨迹 | 新版 | 旧版 |
|---|---:|---:|
| 符合条件的决策次数 | 1086 | 1238 |
| 用王接管 | 826（76.06%） | 571（46.12%） |
| 过牌 | 169 | 577 |
| 用炸弹接管 | 91 | 90 |

两种策略会改变后续牌局，实际轨迹的比例不完全可比。因此对每个符合条件的决策，还在完全相同的手牌和公开上下文上调用另一策略，仅记录其选择，不改变实际对局：

- 合计 2324 次状态观测（可能重复，非独立样本）。
- 新版选择用王：1763/2324，75.86%。
- 旧版选择用王：1116/2324，48.02%。
- 同状态用王率提高 27.84 个百分点。这只证明行为变化，不能证明这些接管提高了胜率。
