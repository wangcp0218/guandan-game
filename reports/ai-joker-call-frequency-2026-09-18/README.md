# 模型调用频率估算

从同一 self-play 种子集合抽取每级 20 组，2–A 共 260 组换队发牌、520 局，在每个决策状态上同时运行旧版及新版模型调用门控。双方实际出牌仍为本地 findBestPlay，没有真实模型请求。基线为 5ad284af9a53ae23056765cbbc8e0af6d99332e7，候选源码见 candidate.patch。

- 共观察 42846 次决策。
- 旧门控触发 17585 次，占 41.04%；每局 33.82 次。
- 新门控触发 27005 次，占 63.03%；每局 51.93 次。
- 调用次数约为原来 1.536 倍，增加 53.57%；每局多 18.12 次。
- 新增触发中，跟牌 9418 次、自由领出 2 次。

每局次数按四个座位均为智能 AI、模型可用估算。真实模型会改变后续牌局，因此不是线上实测；token 成本与延迟未测量，不能直接等同于调用次数增幅。此前 2,600 局实力评估以原报告为准，本轮是调用门控采样。

复现：`node scripts/compare-ai-joker.cjs 20 reports/ai-joker-call-frequency-rerun WORKTREE 5ad284af9a53ae23056765cbbc8e0af6d99332e7`。
