# 单张策略 self-play 评估（2026-09-18）

结论：在本次规则 AI 对战中，昨天的单张策略版本明显优于直接前一版；支持保留这次修改。
这不是大模型参与决策或完整升级比赛的评测结论。

## 版本与方法

- 新版：`280ee3afb7c198e0d9a9a65de94409070c4d28cb`，2026-09-17 提交。
- 旧版：`8ad13ea49bf8fc5ad757a7f79cc66080376ecd4a`，2026-09-16 提交。
- 两个版本均从 Git 提交提取完整源码、独立编译，调用各自的 `findBestPlay`。
- 级牌 2–A，每级 1,000 组独立发牌，共 13,000 组、26,000 局。
- 同一份牌交换新旧策略所属队伍，固定 0 号座位先出；各策略只看到自己的手牌和公开信息。
- 发牌种子：`20260918 + (level - 2) * 100000 + index`，`index=0..999`。
- 采用现有 `simulateEvaluationRound`，不调用 LLM，不进贡，不累计比赛级数；双方级数相同。
- 胜率指队伍获得头游；双上率指本方获得前两名，占全部对局的比例。
- 净升级收益：本方赢记 +1/+2/+3，对方赢记 -1/-2/-3。
- 95% 区间按同一发牌的两局平均值作为独立统计单位，采用正态近似；未将 26,000 局视为独立样本。
- 计算耗时 352.3 秒。

## 总体结果

| 指标 | 新版 | 旧版 |
|---|---:|---:|
| 胜率 | 55.74% | 44.26% |
| 双上率 | 28.08% | 16.87% |
| 每局净升级收益 | +0.3568 | -0.3568 |

新版胜率的近似 95% 置信区间为 55.35–56.13%，
每局净升级收益的近似 95% 置信区间为 0.34–0.37 级。
两个区间均高于持平线（50% / 0），本次样本支持新版优于旧版。
