# 剩余结构评分 self-play 评估（2026-09-18）

本次样本支持新版规则策略小幅优于修改前策略。未修改策略参数来追逐本次结果。

## 方法

- 新版为当前工作区快照，基于 `280ee3afb7c198e0d9a9a65de94409070c4d28cb`；差异保存在 candidate.patch。
- 旧版为 `280ee3afb7c198e0d9a9a65de94409070c4d28cb`，即本次结构评分修改前版本。
- 级牌 2–A，每级 100 组，合计 1,300 组独立发牌；同一发牌交换队伍，共 2,600 局。
- 每局座位 0 先出，仅传递手牌和公开信息。使用 findBestPlay，不调用 LLM。
- 无进贡、无连续升级比赛，双方从相同级牌开始。
- 胜率指获得头游；双上率以全部对局为分母。
- 净升级收益：获胜记 +1/+2/+3 级，失败记 -1/-2/-3 级。
- 95% 置信区间按每组换座两局的平均结果计算，采用正态近似。
- 发牌种子固定；新版手数搜索有 4ms 时间预算，机器负载会影响搜索深度，因此逐局结果不保证完全可复现。
- 四个工作线程，耗时 118.8 秒。已核验种子唯一性、每级数量、总局数；同版本同发牌的单组重复运行检查通过。
